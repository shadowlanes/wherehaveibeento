# Backend - Coming Soon

This directory is reserved for the backend implementation of Where Have I Been To.

## Planned Architecture

The backend will include:
- **Express server** with TypeScript
- **Database** for user data, airports, and travel history
- **API endpoints** for CRUD operations
- **Authentication** integration
- **Cron jobs** for data sync/updates
